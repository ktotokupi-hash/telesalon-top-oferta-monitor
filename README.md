Telesalon Top Oferta Monitor

Opis aplikacji

Telesalon Top Oferta Monitor to prywatna aplikacja służąca do monitorowania ofert sprzedawcy telesalon_pl na platformie Allegro.

Funkcjonalności

Pobieranie informacji o własnych ofertach przez Allegro REST API.

Analiza ofert i powiązanych produktów.

Monitorowanie statusów Top Oferty, jeśli odpowiednie dane są dostępne.

Zapisywanie historii kontroli i generowanie raportów.

Uprawnienia

Aplikacja korzysta z autoryzacji Allegro OAuth i uprawnień odczytu danych ofert sprzedawcy. Nie służy do automatycznej zmiany cen, edycji ofert ani składania zamówień.

Dostępność

Aplikacja przeznaczona jest do wewnętrznego użytku sprzedawcy telesalon_pl na komputerze z Windows 11.
